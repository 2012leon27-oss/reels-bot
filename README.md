# Архитектор мыслей

Приватная мини-страница и Telegram Mini App, которая принимает свободный текст
или голос, сохраняет оригинал и превращает его в полный структурированный документ.

## Что уже работает

- запись с микрофона прямо в браузере;
- загрузка аудио и расшифровка через Whisper;
- пять режимов: авто, проект, встреча, контент и личная заметка;
- структурирование без вымышленных фактов, сроков и исполнителей;
- отдельные блоки решений, задач, идей и открытых вопросов;
- PostgreSQL в production и автоматический SQLite fallback локально;
- постоянная публичная ссылка на каждую заметку;
- история, копирование и выгрузка полного Markdown вместе с оригиналом;
- Telegram Mini App и обработка текста/голосовых прямо в боте;
- авторизация через проверенную подпись Telegram или `APP_ACCESS_KEY`;
- лимиты размера, частоты запросов и безопасный рендеринг без HTML от модели.

## Быстрый запуск

```bash
cp env.example .env
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

Откройте `http://localhost:10000`. Если `APP_ENV=development`, а `BOT_TOKEN` и
`APP_ACCESS_KEY` не заданы, локальный интерфейс доступен без ключа.

Для production обязательны:

- `GROQ_API_KEY` — текстовая модель и транскрибация;
- `DATABASE_URL` — постоянное PostgreSQL-хранилище;
- `APP_ACCESS_KEY` и/или `BOT_TOKEN` — защита расходов API;
- `APP_BASE_URL` — внешний HTTPS URL (на Render определяется автоматически).

`AI_API_KEY`, `AI_BASE_URL` и `AI_MODEL` позволяют подключить другой
OpenAI-совместимый текстовый API. Внутренняя модель Cursor не является внешним
API и не может безопасно вызываться сайтом. Для отдельного провайдера
транскрибации задайте вместе `TRANSCRIPTION_API_KEY` и
`TRANSCRIPTION_BASE_URL`: ключ одного провайдера никогда не отправляется другому.

## Развёртывание

В репозитории есть `render.yaml`: он создаёт постоянно работающий web service и
постоянный PostgreSQL. Используются платные Render-планы, потому что бесплатный
web service засыпает и выключает Telegram polling, а бесплатная база удаляется
после истечения пробного срока. После развёртывания добавьте секрет
`GROQ_API_KEY`. `APP_ACCESS_KEY` генерируется автоматически; его можно
использовать в браузере через кнопку с ключом.

[Развернуть через Render Blueprint](https://render.com/deploy?repo=https://github.com/2012leon27-oss/reels-bot)

Чтобы открыть страницу внутри Telegram:

1. задайте `BOT_TOKEN` и `TELEGRAM_ALLOWED_USER_IDS` (ID через запятую);
2. после первого запуска скопируйте внешний URL сервиса в `APP_BASE_URL`;
3. укажите этот же URL как Mini App URL в BotFather.

## API

- `POST /api/transcribe` — multipart-поле `audio`, возвращает расшифровку;
- `POST /api/structure` — `{"text": "...", "mode": "auto"}`;
- `GET /api/notes` — приватная история владельца;
- `GET /api/notes/{id}` — приватная полная заметка;
- `POST /api/notes/{id}/share` — включить/отозвать ссылку и выбрать публикацию
  оригинала;
- `DELETE /api/notes/{id}` — удаление своей заметки;
- `GET /api/public/{share_id}` — публичная заметка;
- `GET /s/{share_id}` — готовая страница для отправки команде;
- `GET /health` — состояние приложения и базы.

Браузерная авторизация передаётся в `X-App-Access-Key`; Telegram Mini App
использует `X-Telegram-Init-Data`, подпись которого проверяется на сервере.

## Важно о старых секретах

Предыдущая версия репозитория содержала credential-подобные значения в
`env.example`. Удаление из текущей версии не удаляет их из истории Git. Токен
Telegram и ключ Groq необходимо отозвать и выпустить заново перед production.

Подробные решения и дальнейшие этапы описаны в
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
