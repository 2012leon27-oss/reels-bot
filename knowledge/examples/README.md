# Примеры ваших ответов

Сюда можно положить файлы с реальными фрагментами переписки — как вы отвечаете
разным людям. Это помогает нейроагенту копировать ваш тон, а не «типичный ИИ».

## Как использовать

1. Создайте файл на контакт или ситуацию, например:
   - `colleague_scheduling.md` — перенос встреч;
   - `friend_casual.md` — неформальное общение;
   - `client_brief.md` — деловые ответы.
2. Вставьте только **ваши** исходящие сообщения (без чужих секретов).
3. Добавьте короткий комментарий в начале файла: кому и в каком контексте.
4. Не коммитьте переписку с чувствительными данными — держите такие файлы локально.

Ассистент подмешивает эти примеры в промпт вместе с файлами из `knowledge/`.
