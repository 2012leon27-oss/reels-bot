# Персональный контекст собеседников

Для необязательного расширенного контекста создайте файл `<chat_id>.md` в этой
папке. `chat_id` показывается в уведомлении владельцу.

Пример имени: `123456789.md`.

Полезно записать:
- кто этот человек и какие у вас отношения;
- как к нему обращаться;
- текущие проекты или договорённости;
- темы, которых нужно избегать;
- несколько характерных примеров вашего общения.

Короткие заметки можно хранить без файлов командой:
`/note <chat_id> <текст>`.

Новый контакт по умолчанию не получает автоответы. После проверки разрешите их:
`/allow <chat_id>`. Вернуть запрет: `/block <chat_id>`.
